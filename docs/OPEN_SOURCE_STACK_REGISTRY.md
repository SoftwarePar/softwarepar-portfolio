## Routing rules
1. Do not install everything.
2. Prefer native code/CSS/SVG for deterministic UI before adding external generation.
3. For premium web: Frontend Design → Variant/Taste → Impeccable → GSAP/Three.js → browser QA.
4. For SaaS: product spec → schema validation (Zod) → accessible UI primitives → functional flows → runtime/QA.
5. For agents: define contracts, permissions, inputs/outputs and stop conditions before choosing OpenManus, crewAI, DSPy or another orchestrator.
6. For security/OSINT tools: only use for lawful, authorized scenarios.
7. Verify license, activity, compatibility and security before adopting a repository.
8. Treat this registry as durable reference; project-specific adoption belongs in that project's spec/ADR.
