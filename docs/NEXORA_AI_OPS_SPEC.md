# NEXORA AI OPS — Product Demo Specification

## Objective
Build a public, interactive enterprise AI operations demo that proves SoftwarePar can design and engineer a complex SaaS product, not only cinematic landing pages.

## Positioning
NEXORA is an autonomous operations console for orchestrating AI agents, automations, risk, projects, intelligence and team activity across an enterprise.

## Visual direction
- Dark enterprise operating-system aesthetic.
- Dense but controlled information hierarchy.
- Cyan used as a precise system accent, not a decorative gradient.
- Thin borders, low-opacity surfaces, telemetry, graphs and operational states.
- Deliberately different from PIXZEN: no warm editorial beige, no oversized agency typography, no hand imagery, no repeated cinematic landing grammar.

## Phase 1 — Console foundation
Implemented first:
- Responsive application shell.
- Desktop sidebar + mobile navigation.
- Sticky workspace header.
- Operational hero / system status.
- KPI telemetry.
- AI agent mesh table.
- Signal intelligence graph.
- Automation fabric.
- Live activity stream.
- Interactive command palette.
- Production-like states and realistic fictional data.

## Phase 2 — Functional modules
Next:
- AI Agents workspace with detail drawer, role, tools, confidence, recent runs and start/stop controls.
- Automations workspace with trigger/action graph and run history.
- Projects workspace with health, milestones, owners and AI-generated risk flags.
- Intelligence workspace with executive metrics, forecasts and anomaly detection.
- Team workspace with users, permissions and activity.
- Settings workspace with runtime, integrations, security and policies.

## Phase 3 — Product interactions
- Search and command routing.
- Tables with filtering/sorting.
- Agent deployment flow.
- Automation creation flow.
- Drawers/modals.
- Empty/loading/error states.
- Toasts and system feedback.
- Persisted demo state where useful.

## Acceptance criteria
- No horizontal overflow at 320, 375, 430, 768, 1024, 1440 and 1920 px.
- Navigation remains usable with mouse, keyboard and touch.
- Mobile does not depend on hover interactions.
- All visible primary buttons have an action or explicit demo feedback.
- No fake dead links in the product surface.
- UI remains readable at high information density.
- TypeScript strict-compatible; no `any` types.
- No generic startup dashboard aesthetic.
- No PIXZEN visual reuse beyond shared engineering primitives.
- Build must pass before merge.

## Portfolio role
Project 02 in the SoftwarePar public portfolio.

PIXZEN proves cinematic frontend direction and motion.
NEXORA proves SaaS product architecture, enterprise UX and interactive systems engineering.
